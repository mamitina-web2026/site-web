photoshope

photoshope est une logiciel de retouche et de création d'images developpé par la sociéte Abode. Le photoshope sert à :

✔ Rechercher des photos ( lumière , coleur, Effacer une défaut)

✔ Faire des montages ( détourer ,superpaser des images)

✔ Créer des maquettes de site web

✔Créer des affiches à logos, bannières

Voici votre tableau des raccourcis pour utiliser photoshope

Action Raccourcis A quoi ça sert
OUTILS DE BASE
Déplacer V Déplacer une calque / objet
Zoom Z Zoomer et Dézomer
Main( navigateur) H Se déplacer dans l'image
Pipette I Prendre une couleur
Pinceau B Piendre / Dessiner
Gomme E Effacer
texte T Ecrire du texte
Forme U Forme(carré , rond,etc..)
FICHIER/CALQUE
Nouveau fichier Ctrl + N Pour créer une Nouvelle feuille
Ovrir Ctrl + O Pour ouvrir une image dans le photoshope
Enregistrer Ctrl + S Souver ton travail
Exporter JPG / PNG Ctrl + Shift + S Pour exporter l'image final pour le web
Annuler Ctrl + Z Pour Annuler la dernière action
Rétablir Ctrl + Shift + Z Pour rétablir une action annuler
Copier/coller Ctrl + C / Ctrl + V Pour Copier et coller un calque ou sélection
Tout selectionner Ctrl + A Pour selectionner toute l'image
Déselectionner Ctrl + D Pour enlever la selection
Nouveau calque Ctrl + Shift + N Pour créer une nouvelle calque vide
Dupliquer calque Ctrl + J Pour copier le calque actuel
Transformation libre Ctrl + T Pour tourner , déformer l'image
IMAGE / RÉGLAGES
Taille de l'image Ctrl + Alt + I Changer la taille
Taille de la zone Ctrl + Alt + C Changer me canvas
Inverser Ctrl + I Inverser les couleurs
Noir et blanc Ctrl + Shift +U Passer en noir et blanc
Pinceau plus grand ] Augmenter le Pinceau
